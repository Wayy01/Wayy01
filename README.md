## 🚀 Founder of Just Dashboard

<a href="https://just-dashboard.com">
  <img src="./profile/just-dashboard.svg" width="100%" alt="Just Dashboard: one authenticated UI for one Linux server. Metrics, Docker, a real shell, files, git, databases, deploys and backups, behind a login on your private network. Visit just-dashboard.com." />
</a>

**[Just Dashboard](https://just-dashboard.com)** puts metrics, Docker, processes, logs, a real shell, files, git, databases, the reverse proxy, the firewall, backups and deploys into one UI for one Linux server. It sits behind a login that lives on your private network. It's free, and every feature stays free.

<table>
  <tr>
    <td width="50%">🚢 <b>Deploys from anything</b><br/><sub>A repository, an image, a template or a Compose file. Releases are immutable, so a rollback brings back what ran before.</sub></td>
    <td width="50%">🗄️ <b>Databases you can hand out</b><br/><sub>Browse, query and diagram several engines from one place. A database started here gets its own connection string.</sub></td>
  </tr>
  <tr>
    <td>🧩 <b>Reviewed one-click templates</b><br/><sub>PostgreSQL, Redis, n8n, Grafana, Uptime Kuma, Ollama and more. Each one says how you sign in.</sub></td>
    <td>🔁 <b>Push to deploy, with previews</b><br/><sub>Pull-request previews and notifications to Discord, Slack, Telegram, e-mail and webhooks.</sub></td>
  </tr>
  <tr>
    <td>💾 <b>Backups that know the gaps</b><br/><sub>Every volume, stack, deployment and database, plus a list of what isn't backed up yet.</sub></td>
    <td>🔐 <b>Private by default</b><br/><sub>Built for Tailscale or an SSH tunnel, with two-factor sign-in and an audit log of every change.</sub></td>
  </tr>
</table>
